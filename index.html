Como funciona
  1. Você é enviado para o login do Mercado Livre.
  2. Após autorizar, o ML devolve um code nesta página de callback.
  3. A página monta o curl de troca do code por access_token.
  4. Você roda esse curl no seu terminal, informando o client_secret.

O client_secret nunca é digitado nem armazenado aqui. Página estática, sem servidor e sem coleta de dados.
